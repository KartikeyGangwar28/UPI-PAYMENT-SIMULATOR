# UPI-PAYMENT-SIMULATOR
A modern **UPI (Unified Payments Interface) Simulator** built to demonstrate how digital payment systems work. This project simulates core UPI functionalities such as user authentication, bank account linking, money transfers, transaction history, and payment requests in a safe, educational environment.

> ⚠️ **Disclaimer:** This project is for educational and demonstration purposes only. It does **not** connect to real banks or process actual financial transactions----
## ✨ Features
- 🔐 User Authentication (Login / Register)
- 🏦 Link Multiple Bank Accounts
- 💰 Check Account Balance
- 📤 Send Money
- 📥 Receive Money
- 📜 Transaction History
- 📱 UPI ID Generation
- 💳 QR Code Payment Simulation
- 📊 Dashboard with Account Overview
- ⚡ Real-time Transaction Simulation
- 🎨 Responsive and User-Friendly UI
